# Company Data Analysis & Excel Dashboard

## Overview
This repository contains an end-to-end data analysis project built using Microsoft Excel and Google Sheets. The goal of the project is to analyze company-level data, identify patterns and trends, and present the findings through an interactive dashboard that makes the insights easy to understand at a glance.

The project is intended for anyone who wants to quickly understand:
- What data was analyzed
- What business problem the analysis addresses
- What tools and techniques were used
- What insights and findings were discovered

## Business Problem

The company needed a clear view of its performance across different departments, regions, or time periods, but the raw data was scattered across multiple sheets and difficult to interpret. Decision-makers lacked a single, easy-to-read view that could help them:

- Track key performance indicators (KPIs) over time
- Identify underperforming areas that need attention
- Compare performance across categories (region, product, department, etc.)
- Make faster, data-driven decisions

This project addresses that gap by consolidating the raw data into a clean, structured format and presenting it through a visual dashboard.

## Problem Statement
1. How can the company's raw operational data be structured and analyzed to reveal meaningful trends?
2. Which factors are driving the differences in performance across [departments / regions / products], and how can this be visualized so that stakeholders can act on it quickly?

## Dataset
- **Format:** Excel (.xlsx) / CSV

- **Microsoft Excel** – Data cleaning, transformation, pivot tables, and formulas (VLOOKUP, INDEX-MATCH, IF, SUMIFS, COUNTIFS, etc.)
- **Google Sheets** – Collaborative data review and secondary analysis
- **Excel Dashboard** – Interactive charts, slicers, and KPI cards for visual reporting
- **Pivot Tables and Pivot Charts** – Summarizing large datasets for quick insights
- **Conditional Formatting** – Highlighting outliers, trends, and performance thresholds

## Approach and Methodology

1. **Data Collection** – Gathered raw data from Kaggle.
2. **Data Cleaning** – Removed duplicates, handled missing values, standardized formats, and corrected inconsistent entries.
3. **Data Transformation** – Created calculated columns and pivot tables to summarize the data by relevant categories.
4. **Exploratory Analysis** – Studied trends, distributions, and relationships within the data to understand underlying patterns.
5. **Dashboard Design** – Built an interactive Excel dashboard using charts, slicers, and KPI indicators to make the analysis easy to explore and understand.
6. **Insight Generation** – Interpreted the results to answer the business problem and support the problem statements.

## Dashboard Features
- Summary KPI cards (e.g., total revenue, total profit, growth rate)
- Trend charts showing performance over time
- Category-wise comparison charts (region, department, product, etc.)
- Interactive slicers/filters for dynamic exploration of the data
- Clean, color-coded layout for quick readability
